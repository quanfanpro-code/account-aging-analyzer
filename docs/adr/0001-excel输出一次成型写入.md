# Excel 输出弃用 openpyxl 逐格两遍写入，改为标准库一次成型 XML 写入

四个审计工具（账龄分析工具、账龄分析 Skill、序时账对方科目、往来占用统计）的 Excel 结果文件原先用 openpyxl 先逐格写一遍值、再逐格刷一遍字体边框数字格式，5 万行导出需约 26 秒；现改为 make_excel.py 内置的写入器直接拼接 sheet XML 与 styles.xml 一次打包（excel-fast-writer 技能模式），同规模导出降至约 4 秒，且输出经金样逐格对比与旧版语义一致。排版后处理（页签色、备注高亮、班福折线图）改为写入前的表计划参数/回调，不再出现"保存后再打开整本文件补排版"的第二遍读写；openpyxl 仍用于读取输入和测试断言，但不再是输出路径的依赖。
