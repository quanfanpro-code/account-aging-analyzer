# Ponytail 精简需求

## 背景与目标

按已批准的冗余审计精简往来账龄分析工具，降低维护成本，不改变正式计算、界面和 Excel 输出。

## 范围

- 删除历史需求、设计和实施记录，仅保留本次可追溯记录。
- 删除手工模拟和集成验证脚本，以现有自动测试替代。
- 收窄 make_excel.py，只保留正式深海蓝报表导出。
- 简化方向判断和报表导入路径。
- 将 pytest 从普通用户运行依赖中移出。
- 同步更新 README、本机程序副本和云端仓库。

## 明确保留

- 多序时账合并、借贷方向自动判断、六个 Sheet 输出。
- GUI、列映射、FIFO 计算、异常提示和现有 Excel 内容及样式。

## 验收标准

- 全量自动测试通过。
- 正式入口可导入，Excel 表头、Sheet 名和深海蓝样式测试通过。
- README 与实际文件、依赖和测试数量一致。
- 本机受控文件与云端提交逐项一致。
