# 设计：期初余额可选，只有序时账也能算账龄

- 日期：2026-08-24
- 状态：待实施
- 依据需求：docs/requirements/2026-08-24-期初可选-requirement.md

## 方案比较

**方案 A：只改界面层（推荐）**
- step_import.validate()：期初余额改为可选。
- step_result._run_calculation()：未选期初时按空表（期初全 0）继续。
- 期初卡片加提示。
- 优点：改动小、不影响核心引擎、有期初场景不变。

**方案 B：加"本期期初为 0"开关**
- 界面加开关，勾选时整块期初区域置灰。
- 缺点：改动大，需求已排除。

推荐方案 A。

## 数据流（未选期初时）

1. 第一步只选序时账，期初文件留空。
2. 校验放行（期初可选）。
3. 第三步计算：opening_df 为空 DataFrame（含标准列），opening_date 传 None，opening_aging_columns 为空。
4. 引擎按期初 0 正常计算。

## 错误处理

- 未选期初不报错，日志提示"未选择期初余额，期初按 0 计算"。
- 序时账仍必选，缺失仍报错（维持现有行为）。

## 测试策略

- 新增无期初场景测试：只有序时账，验证账龄正确、期初余额为 0。
- 现有有期初测试全部保持通过。
