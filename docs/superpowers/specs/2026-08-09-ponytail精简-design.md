# Ponytail 精简设计

## 方案比较

1. 推荐：各仓就地删除未调用能力，保留深海蓝导出和现有调用接口。改动最小，回归范围清楚。
2. 把四仓 Excel 导出统一成共享包。重复更少，但引入跨仓版本和发布耦合，本次不采用。
3. 只删除文档，不动生产代码。风险最低，但无法完成已批准的代码精简，本次不采用。

## 设计

保留 make_excel 的数据写入、样式、公式和进度能力，删除 beautify、独立 CLI 和多主题选择。报告层直接导入随仓模块。方向判断改为无状态函数。手工验证脚本由现有自动测试替代。

删除项均可从本次提交的父版本恢复。测试重点为 FIFO、方向判断、合并、六 Sheet 报告及深海蓝表头。
